A selection of open-source projects and research code.

## Research Code

- **[LaneGNN / UrbanLaneGraph](https://github.com/jzuern/lanegnn)** — Dataset, benchmark, and code for *Learning and Aggregating Lane Graphs for Urban Automated Driving* (CVPR 2023).
- **[AutoGraph](https://github.com/jzuern/autograph-pub)** — Code for *AutoGraph: Predicting Lane Graphs from Traffic Observations* (RA-L 2024).
- **[HeatNet](https://github.com/jzuern/heatnet-pub)** — Code for *HeatNet: Bridging the Day-Night Domain Gap in Semantic Segmentation with Thermal Images* (IROS 2020).
- **[WayveScenes101](https://github.com/wayveai/wayve_scenes)** — Dataset and benchmark for novel view synthesis in autonomous driving.

## Fun

- **[SPH Fluid Simulation in Fortran90](https://github.com/jzuern/sph-fluidsim-fortran)** — A minimalistic particle-based 3D smoothed-particle-hydrodynamics fluid simulator, implemented in Fortran90.

    ![SPH fluid simulation](/images/fluidsim.jpg)

- **[sph-fluidsim](https://github.com/jzuern/sph-fluidsim)** — A particle-based 2D fluid simulation in C++.
- **[continuum](https://github.com/jzuern/continuum)** — A lightweight GPU-accelerated 2D physics library.
- **[robot-localization](https://github.com/jzuern/robot-localization)** — A small 2D robot localization game using Kalman filtering, written in C++11.
